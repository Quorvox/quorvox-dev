# Изменения

## 0.11.0

- **Два языка:** русский и английский. По умолчанию по языку VS Code (русский → русский, остальное → английский); переключатель «Авто / Русский / English» в меню «…» боковой панели Quorvox и настройка `quorvox.language`. Сообщения, карта, дашборд и подсказки меняются сразу. Заголовки панелей и названия команд следуют языку VS Code.
- **Python:** маршруты Flask и FastAPI (декораторы, Blueprint и APIRouter с префиксами, методы, параметры), переменные `os.environ`/`os.getenv`, запуск одной кнопкой (flask --debug / uvicorn --reload, подхватывается venv), проверки «фронт зовёт адрес, которого нет», карта проекта.
- **Импорт проектов от нейросетей:** перед установкой мастер показывает честный отчёт (что найдут проверки, нет ли Node или Python на компьютере), ставит Python-пакеты в `.venv` внутри проекта и только готовыми пакетами (`--only-binary`).
- **Подсказки для вёрстки:** картинка без `alt`, нет `viewport`, `lang`, `title`, `target="_blank"` без `rel="noopener"`.
- **Перенос файлов:** ссылки теперь чинятся и при обычном перетаскивании в проводнике и по F2 (Ctrl+Z отменяет всё вместе). Настройка `quorvox.fixLinksOnMove`.
- Исправлено: подчёркивание в редакторе больше не зависит от текста сообщения; распаковка zip на Windows использует системный tar.

## 0.10.0

- **Безопасная перекладка:** перенос файлов и папок из проводника с автоматической починкой ссылок в HTML, CSS, JS/TS и сервере Express, предпросмотр правок, проверки после переноса и отмена переноса.
- **Импорт проекта:** GitHub-ссылка или zip → осмотр (стек, менеджер пакетов, переменные окружения) → мастер подготовки: установка зависимостей без скриптов установки, `.env` из образца, запуск и карта.
- **Доверие к папке:** в недоверенной папке запуск сервисов, выкладка, доступ с телефона и установка зависимостей отключены.

## 0.9.0

Первый публичный релиз.

- **Запуск и живая разработка:** одна кнопка поднимает все сервисы проекта, перезапуск при изменении файлов, обновление страницы в браузере, общий лог с фильтром.
- **Сайты без бэкенда:** встроенный статический сервер для папки с `index.html` (или несколькими сайтами), проекты на Vite и Next подключаются без вмешательства в их перезагрузку.
- **Карта проекта:** страницы → CSS и скрипты → серверные файлы → таблицы базы и внешние сервисы, с объяснениями простыми словами; управление колёсиком, правой кнопкой мыши и пробелом.
- **Проверки:** адреса API, которых нет на сервере, неверный метод, переменные окружения, конфликт портов, мёртвый CSS и опечатки в классах, битые ссылки на файлы (в том числе разница в регистре).
- **Подсказки прямо в редакторе:** подчёркивания по несохранённому тексту, автодополнение классов из CSS и адресов API, переход к определению по Ctrl+клику, подсказка при наведении. Включается и выключается в настройках.
- **Телефон:** QR-код и доступ по Wi-Fi (только по явному включению), ошибки из браузера и с телефона попадают в логи.
- **Выкладка на свой сервер (VPS):** по ssh-ключу, с копией старой версии, откатом и подтверждением «работает».
